QUICK START:
============
1. cd backend && npm run dev
2. cd frontend && python3 -m http.server 8080
3. Open http://localhost:8080
4. Create session → Join in new tab → Test!

FEATURES:
=========
✅ Facilitator dashboard (create/manage sessions)
✅ Participant interface (join/view sessions)
✅ Real-time WebSocket updates
✅ Modern responsive UI
✅ Toast notifications
✅ Connection monitoring
✅ Session management (pause/end)
✅ Live participant tracking
✅ Score display
