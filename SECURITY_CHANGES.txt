================================================================================
VALIDATION RULES
================================================================================

JWT_SECRET:
- Minimum length: 32 characters
- Must be cryptographically random
- Cannot contain: 'secret', 'change', 'production', 'dev', 'test', '12345'
- Error message includes generation command

SESSION_SECRET:
- Minimum length: 32 characters
- Must be cryptographically random
- Cannot contain placeholder patterns
- Must be different from JWT_SECRET

QR_HMAC_SECRET:
- Minimum length: 32 characters
- Must be cryptographically random
- Cannot contain placeholder patterns
- Must be different from other secrets

QR Code Data:
- participantId: Valid UUID v4
- sessionId: Valid UUID v4
- billingsScore: Number between 0-1
- expiresAt: Valid ISO 8601 datetime
- signature: 64-character hex string
- Maximum size: 10KB
- No extra properties allowed

Billings Scores:
- Must be between 0 and 1
- Must be finite (not NaN or Infinity)
- Type must be number

CORS Origins:
- Must be valid URLs or "*"
- Properly trimmed
- Warning if "*" in production
